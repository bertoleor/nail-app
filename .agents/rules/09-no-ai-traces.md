# No AI Traces - Eliminar Rastros de IA

## Principio Fundamental

El código de NAIL-APP debe parecer escrito por humanos, no generado por IA. Eliminar todos los rastros de generación automática.

---

## PROHIBIDO en Código Final

### Atributos `style` inline

En Tailwind v4, `style={}` en elementos HTML es evitable al **100%**.

```tsx
// ❌ PROHIBIDO — HTML con inline style
<div style={{ color: '#fff', padding: '16px' }} />

// ✅ CORRECTO — clases Tailwind
<div className="text-white p-4" />

// ✅ EXCEPCIÓN — CSS variable dinámica computada desde JS runtime
<div style={{ '--progress-width': `${progress}%` } as React.CSSProperties} />
```

### Números Mágicos

```typescript
// ❌ PROHIBIDO
if (price > 5000) { ... }
setTimeout(fn, 3000);

// ✅ CORRECTO
const FREE_SHIPPING_THRESHOLD = 5000;
const CALCULATION_DEBOUNCE_MS = 3000;
if (price > FREE_SHIPPING_THRESHOLD) { ... }
```

### Comentarios Explicativos

```typescript
// ❌ PROHIBIDO

  // Get base price
```

## PROHIBIDO en UI

### Textos Placeholder

```tsx
// ❌ PROHIBIDO
<p>Lorem ipsum dolor sit amet</p>
<h1>Your Title Here</h1>

// ✅ CORRECTO
<p>Calculá el precio de tu servicio en segundos.</p>
<h1>Calculadora de Precios</h1>
```

### Botones Sin aria-label

```tsx
// ❌ PROHIBIDO
<button onClick={handleClick}>
  <XIcon />
</button>

// ✅ CORRECTO
<button onClick={handleClick} aria-label="Cerrar modal">
  <XIcon aria-hidden="true" />
</button>
```

## NOMBRES DE VARIABLES

### Prohibidos

```typescript
// ❌ PROHIBIDO
let data, result, output, temp, value, item, element, thing, stuff, obj, arr, func, callback;

// ✅ CORRECTO
let bookingResult, formattedReceipt, totalPrice, currentStep;
```

### Patrones Correctos

| Tipo      | Patrón            | Ejemplo                           |
| --------- | ----------------- | --------------------------------- |
| Booleanos | is/has/can/should | `isLoading`, `hasPermission`      |
| Arrays    | plural            | `bookings`, `services`            |
| Objetos   | singular          | `booking`, `service`              |
| Funciones | verbo             | `calculateTotal`, `validateInput` |
| Eventos   | handle + evento   | `handleClick`, `handleSubmit`     |
